# Klipday

A performance-driven short-form video clipping marketplace connecting brands and creators in Indonesia. Brands receive organic reach with escrow budget protection; clippers monetize edits per verified view (CPM).

> **Interactive Documentation**: Open [`documentation.html`](file:///C:/Projects/klipday/documentation.html) in your browser for the local interactive documentation experience with visual architecture and navigation.

## About Klipday

### The Marketplace Model
Brands and small businesses (UMKM) often face high upfront agency retainers and unpredictable influencer sponsorships with no guaranteed return on investment. At the same time, thousands of video editors and content creators (clippers) know how to create viral short-form videos but lack direct access to brand partnerships.

Klipday solves this disconnect with an escrow-backed, performance-based marketplace. Brands set a target budget and a Cost Per Mille (CPM) rate—paying strictly for verified video views. Creators produce and publish video edits, earning guaranteed income backed by locked escrow funds.

### For Brands
- **Zero Wasted Spend**: Pay only for actual verified views generated by approved clips, not for empty promises or flat posting fees.
- **Escrow Budget Protection**: Campaign funds are securely locked in escrow before a campaign goes live. Unspent budget is automatically refunded when the campaign ends.
- **Multiple Campaign Categories**: Promote physical products (e-commerce, F&B, beauty, fashion), digital services (apps, SaaS, courses), or media content.
- **Full Curation Control**: Review every submitted clip before it begins tracking views. Approve high-quality edits, request revisions (up to 2 rounds), or reject non-compliant submissions.

### For Clippers (Creators)
- **Open Earning Opportunities**: Anyone with short-form editing skills can participate—no large follower count or prior influencer status required.
- **Guaranteed Payouts**: All active campaigns are backed by pre-funded escrow. If your video is approved and gets views, your payment is guaranteed.
- **Post-First Flexibility**: Produce content according to the creative brief and post directly to your own TikTok account first, then submit the live link to Klipday.
- **Transparent Metrics**: Track your verified views and accumulated earnings in real time with clear per-clip earning caps and minimum view thresholds.

## How It Works

### Brand Workflow
1. **Deposit Funds**: Top up your brand wallet balance via Indonesian payment methods (Bank Transfer, Virtual Account, or QRIS).
2. **Create Campaign**: Configure your campaign through a 6-step guided wizard: basic information, creative brief and posting rules, CPM rate and view caps, downloadable footage/assets, review summary, and escrow lock.
3. **Admin Review & Launch**: Once approved by the internal admin, the campaign budget is locked in escrow and the campaign appears live on the marketplace.
4. **Curate Submissions**: As clippers submit videos, review them in your curation queue. Approve compliant clips or request revisions with specific feedback.
5. **Settlement**: Approved videos earn per verified view until the campaign budget is exhausted or the deadline arrives. Any remaining unspent escrow returns to your wallet.

### Clipper Workflow
1. **Discover Campaigns**: Browse active marketplace campaigns, review creative briefs, check CPM rates, and download raw media assets.
2. **Verify TikTok Handle**: Link your TikTok account using a quick, one-time profile bio verification handshake (`KD-XXXX` code). Once verified, the code can be removed from your bio immediately.
3. **Produce & Post Video**: Edit your clip using brand guidelines and required hashtags, then publish the video directly to your verified TikTok account.
4. **Submit Clip**: Open the campaign page and submit your live video using the in-context submission dialog (select directly from your recent TikTok feed or paste the video link).
5. **Earn & Withdraw**: Once approved by the brand, your video accrues earnings as verified views grow. Request withdrawals to your Indonesian bank account or e-wallet once your balance reaches the minimum threshold (Rp50,000).

## Core Features

### Escrow & Wallet Ledger
Double-entry financial ledger managing wallet deposits, campaign budget locks, creator earnings distributions, and refunds. Unused campaign funds return to the brand balance upon settlement, ensuring zero financial risk.

### 6-Step Campaign Wizard
Self-contained campaign builder walking brands through:
- **Campaign Information**: Title, category, product description, and promotional goals.
- **Creative Brief & Rules**: Talking points, required hashtags/mentions, dos & don'ts, and call to action.
- **CPM & View Economics**: Rate per 1,000 views, minimum threshold to start earning, per-clip maximum view cap, and total budget.
- **Media Assets**: Upload product footage, image assets, and reference video links.
- **Review Summary**: Final audit of all parameters before funding.
- **Escrow Checkout**: Instant budget lock from the brand wallet.

### Anti-Hijacking TikTok Bio Verification
Account linking system using a one-time ownership challenge token (`KD-XXXX`, 10-minute expiry) verified via profile scrapers. Enforces database-level uniqueness (`@@unique([platform, username])`) to prevent account squatting, while saving social avatars permanently to Supabase Storage to avoid expiring CDN URLs.

### In-Context Post-First Submission Dialog
Two-column modal dialog embedded directly in the campaign detail page:
- **Left Column**: Campaign guidelines, CPM rates, and reward metrics overview.
- **Right Column**: 4-step submission wizard covering brief compliance confirmation, handle verification, video selection (recent TikTok gallery or manual URL), and submission review.

### Role-Adaptive Interface
Distinct interfaces tailored to user roles:
- **Brand**: Campaign creation, escrow tracking, submission review queue, and performance analytics.
- **Creator (Clipper)**: Campaign discovery, social account management, personal submission tracking, and wallet withdrawals.
- **Admin**: Campaign moderation, deposit slip verification, settlement reviews, and manual payout execution.

## Tech Stack & Architecture

### Backend (`backend/`)
- **Runtime & Language**: Node.js & TypeScript
- **Framework**: Express 5.1
- **Database & ORM**: PostgreSQL (Supabase) with Prisma ORM 7.9
- **Validation & Security**: Zod 4.4, Helmet, CORS, Cookie-parser, Bcrypt, JWT
- **Architecture**: Modular feature packages (`backend/src/features/`) with fast-fail security guards, single-query tenant ownership checks, and standardized API envelopes (`SendSuccess`, `SendError`).

### Frontend (`frontend/`)
- **Framework & Language**: React 19 & TypeScript
- **Bundler & Tooling**: Vite 8
- **Styling**: Tailwind CSS v4, Lucide Icons
- **State & Data Fetching**: TanStack Query v5 & Axios
- **Forms & Validation**: React Hook Form, Zod
- **UI Primitives**: Radix UI & shadcn/ui design primitives
- **Routing**: React Router v8 (Data Router with route code splitting and lazy loading)
- **Architecture**: Modular feature packages (`frontend/src/features/`) with compile-time pure types, zero magic strings, and clean minimalist design.

## Getting Started

### Prerequisites
- Node.js (>= 20.x)
- npm (>= 10.x)
- PostgreSQL database (local instance or Supabase)

### 1. Clone the Repository
```bash
git clone https://github.com/your-username/klipday.git
cd klipday
```

### 2. Backend Setup
```bash
cd backend
npm install

# Configure environment variables
cp .env.example .env
# Edit .env with your DATABASE_URL, JWT_SECRET, and SUPABASE credentials

# Generate Prisma client and synchronize database schema
npx prisma generate
npx prisma db push

# Start development server
npm run dev
```
The backend API server will run at `http://localhost:3000`.

### 3. Frontend Setup
```bash
# In a new terminal window
cd frontend
npm install

# Start development server
npm run dev
```
The frontend client will run at `http://localhost:5173` with Vite's proxy automatically forwarding `/api` requests to the backend at port 3000.
