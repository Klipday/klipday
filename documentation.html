Klipday Platform

Marketplace dua arah yang menghubungkan brand (produk, konten digital, dan jasa) dengan para kreator video pendek (clippers) di Indonesia berbasis kompensasi penayangan nyata (Pay-per-View / CPM).

Tentang Klipday

Solusi Pemasaran Organik & Peluang Monetisasi Kreator

Klipday hadir untuk memecahkan dua masalah utama dalam ekosistem konten video pendek di Indonesia:

Bagi Brand & UMKM

Mendapatkan jangkauan promosi viral di media sosial tanpa harus membayar retainer agensi yang mahal atau risiko endorse tanpa hasil. Brand hanya membayar untuk hasil performa tayangan valid (views) yang nyata.

Bagi Kreator & Clippers

Mendapatkan penghasilan sampingan langsung dari keahlian mengedit dan mendistribusikan video pendek. Kreator tidak perlu menunggu tawaran endorse pribadi—cukup pilih kampanye, buat klip, dan dapatkan bayaran bergaransi escrow.

Kategori Kampanye yang Didukung

Brand dapat mendaftarkan kampanye untuk tiga jenis penawaran:

  • Produk Fisik (Physical Products): Skincare, fashion, kuliner/F&B, gadget, dan barang konsumen harian.
  • Konten Digital: Kursus online, podcast, media berita, aplikasi web/mobile, dan webinar.
  • Layanan & Jasa (Services): Jasa profesional, edukasi, travel & hospitality, dan event.

Peran Pengguna (Roles)

Sistem Akses Multi-Peran Terisolasi

Platform mengisolasi alur kerja dan navigasi berdasarkan peran pengguna yang dipilih saat pendaftaran.

Peran Deskripsi Singkat Akses & Kemampuan Utama
BRAND Pemilik bisnis, UMKM, atau pemasar produk/jasa. Top-up dompet, buat kampanye via wizard 6-langkah, kunci dana escrow, kurasi dan ulas video masuk kreator.
CREATOR Editor video pendek / clippers di media sosial. Eksplorasi kampanye, hubungkan akun TikTok via kode bio, kirim link video live, lacak status penayangan & estimasi earning.
ADMIN Pengelola internal platform Klipday. Ulas penerbitan kampanye baru, pantau verifikasi pembayaran/top-up dompet, verifikasi settlement akhir, dan eksekusi pencairan saldo.

Cara Kerja Marketplace

Alur End-to-End Dari Pembuatan Hingga Pencairan

Berikut adalah alur lengkap perjalanan kampanye dari sisi Brand dan sisi Kreator.

1. Alur Brand

1

Top-up Saldo Dompet Brand

Brand mengisi saldo dompet melalui metode transfer bank, Virtual Account, atau QRIS untuk mendanai anggaran kampanye.

2

Buat & Konfigurasi Kampanye

Menentukan brief kreatif, aturan narasi, aset video/materi mentah, tarif CPM (Rp per 1.000 views), batas minimum dan maksimum views, serta total anggaran.

3

Penguncian Anggaran di Escrow

Total dana kampanye dikunci secara aman di rekening penampung (escrow) agar kreator mendapatkan kepastian pembayaran.

4

Kurasi Pengajuan Video

Brand meninjau video yang disubmit kreator: Setujui (Approve), Minta Revisi (maksimal 2 putaran), atau Tolak (Reject).

2. Alur Kreator (Clipper)

1

Pilih Kampanye & Unduh Materi

Kreator menjelajahi daftar kampanye aktif, membaca pedoman brief, dan mengunduh aset materi video atau referensi.

2

Hubungkan & Verifikasi Akun TikTok

Memasukkan username TikTok dan menaruh kode verifikasi unik sementara (KD-XXXX) di bio profil TikTok untuk membuktikan kepemilikan akun.

3

Unggah Video ke TikTok (Post-First Model)

Kreator memproduksi video klip dan mengunggahnya langsung ke akun TikTok pribadi sesuai panduan brief, hashtag, dan hook yang ditentukan.

4

Kirim Link Video di Dialog Klipday

Memilih video yang baru diunggah melalui galeri profil TikTok atau memasukkan link URL video live ke modal pengajuan Klipday.

5

Dapatkan Penghasilan Berdasarkan Tayangan

Setelah video disetujui, jumlah penayangan valid dihitung dan dikalikan dengan tarif CPM kampanye hingga batas kuota anggaran terpenuhi.

Fitur-Fitur yang Sudah Terimplementasi

Status Modul Fungsional di Kode Program

Modul-modul berikut telah dibangun secara lengkap di sisi backend (Express/Prisma) dan frontend (React 19).

Autentikasi & Akun Selesai

Pendaftaran & masuk dengan email + password. Password di-hash menggunakan Bcrypt. Autentikasi berbasis JWT yang disimpan di HTTP-only cookie dengan isolasi role guard otomatis (BRAND, CREATOR, ADMIN).

Dompet Brand & Escrow Selesai

Manajemen saldo dompet brand, pengajuan isi ulang (top-up), riwayat transaksi, penguncian saldo ke escrow saat kampanye dibuat, serta fitur permintaan penarikan dana (withdrawal).

Wizard Pembuatan Kampanye Selesai

Formulir multi-tahap (6 langkah): Info Dasar, Brief & Aturan, Model Imbalan CPM & View, Materi & Tautan Footage, Rangkuman Ulasan, dan Pembayaran Escrow via dompet brand dengan proteksi penyimpanan draft otomatis.

Verifikasi Bio Akun TikTok Selesai

Handshake verifikasi anti-pembajakan: kode unik sekali pakai KD-XXXX (kadaluarsa 10 menit) dimasukkan ke bio TikTok, diperiksa otomatis oleh scraper, dan dikunci permanen pada database (unique([platform, username])).

Pengajuan Video Post-First Selesai

Dialog pengajuan video 2-kolom langsung di halaman detail kampanye: Pengecekan Brief → Konfirmasi Akun → Pemilih Video TikTok atau Link Langsung → Rangkuman Pengajuan dengan draft auto-recovery.

Antrean Kurasi Pengajuan Brand Selesai

Tabel dan kartu ulasan video untuk brand: putusan Setujui, Minta Revisi dengan catatan terstruktur, atau Tolak, lengkap dengan filter status dan riwayat pengajuan.

Teknologi Stack

Fondasi Perangkat Lunak Modern & Handal

Dibangun dengan arsitektur monorepo terstruktur, memisahkan backend API dan frontend SPA dengan TypeScript end-to-end.

Backend (backend/)

REST API modular berbasis Express dan Prisma:

  • Runtime: Node.js & TypeScript
  • Framework: Express 5.1
  • Database ORM: Prisma 7.9 dengan PostgreSQL
  • Validasi Data: Zod 4.4
  • Keamanan: Helmet, CORS, Cookie-parser, Bcrypt, JWT
  • Database Hosting: Supabase PostgreSQL (Session Pooler)

Frontend (frontend/)

Single Page Application modern berbasis React:

  • Framework: React 19 dengan TypeScript
  • Bundler: Vite 8
  • Styling: Tailwind CSS v4 & Lucide Icons
  • State & Data Fetching: TanStack Query v5 & Axios
  • Formulir: React Hook Form & Zod Resolver
  • UI Primitives: Radix UI & shadcn/ui
  • Routing: React Router v8 (Data Router & Code Splitting)

Organisasi Modul Berdasarkan Fitur (Feature-Driven Architecture)

Kode backend dan frontend disusun rapi berdasarkan domain fitur (bukan berdasarkan lapisan teknis), mempermudah pemeliharaan dan skalabilitas.

Panduan Instalasi & Menjalankan Proyek

Langkah Cepat Memulai Pengembangan Lokal

Ikuti instruksi berikut untuk menjalankan server backend dan client frontend di komputer lokal Anda.

1. Persiapan Lingkungan (Prerequisites)

Pastikan perangkat Anda telah terpasang: Node.js (≥ 20.x), npm (≥ 10.x), dan akses ke basis data PostgreSQL (lokal atau instance cloud Supabase).

2. Menjalankan Backend

Terminal (Backend Setup) 
# Masuk ke folder backend
cd backend

# Pasang dependensi
npm install

# Buat file konfigurasi environment
cp .env.example .env

# Generate client Prisma & sinkronkan skema database
npx prisma generate
npx prisma db push

# Jalankan server backend dalam mode pengembangan (port 3000)
npm run dev

3. Menjalankan Frontend

Terminal (Frontend Setup) 
# Buka terminal baru dan masuk ke folder frontend
cd frontend

# Pasang dependensi
npm install

# Jalankan server pengembangan Vite (port 5173 dengan proxy otomatis ke backend)
npm run dev

Setelah berjalan, buka browser di alamat http://localhost:5173 untuk mengakses antarmuka aplikasi web Klipday.
