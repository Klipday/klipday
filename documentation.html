MARKETPLACE • INDONESIA • TIKTOK-FIRST

Klipday Platform

A performance-driven clipping marketplace connecting brands with short-form video creators in Indonesia. Brands get organic viral reach with escrow budget protection; clippers monetize edits per verified view (CPM).

Core Dynamic

01 / MARKET MODEL

Klipday bridges the gap between commercial demand for viral social media clips and creators looking to earn without waiting for individual sponsorship deals.

Brands & MSMEs

Eliminate expensive agency retainers and unmeasured influencer spend. Brands set a target CPM (e.g. Rp15,000 / 1K views) and pay strictly for real, verified view performance.

Clippers & Creators

Monetize editing skills immediately. Anyone who can produce engaging short-form TikTok content can join open campaigns, post to their own channels, and earn guaranteed payouts backed by escrow.

Campaign Types

02 / ENTITY COVERAGE

Brands can launch campaigns for three distinct types of commercial offerings:

01

Physical Products

E-commerce goods, skincare, fashion, food & beverage, electronics, and daily consumer products. Creators receive raw footage or product hooks to produce shoppable-style clips.

02

Digital Content

Online educational courses, podcasts, media publications, software applications, and webinars. Creators highlight engaging moments, clips, or quotes.

03

Services

Professional services, health & wellness clinics, travel agencies, and event organizers seeking localized engagement in Indonesia.

User Roles

03 / PERMISSION BOUNDARIES

The system maintains strict tenant isolation across three roles defined during authentication:

Role Context Key Responsibilities
BRAND Business / Advertiser Top-up wallet balance, build 6-step campaigns, lock escrow funds, curate & review creator video submissions.
CREATOR Clipper / Content Producer Browse active marketplace, link & verify TikTok profile via bio code, post videos directly to TikTok, submit live links, track earnings.
ADMIN Internal Ops Review new campaigns, audit top-up proof slips, verify settlement view reports, and approve creator withdrawal disbursements.

Brand Workflow

04 / END-TO-END ADVERTISER JOURNEY

How a brand launches and manages a campaign from inception to completion:

Step 1

Wallet Deposit

Brand tops up account balance via Indonesian bank transfer, Virtual Account, or QRIS. The platform logs the pending deposit request for admin approval.

Step 2

Campaign Creation (6-Step Wizard)

Brand specifies campaign details, creative brief (narrative, hooks, mandatory hashtags), reward rules (CPM rate, min views threshold, max views cap, total budget), and raw video footage/assets.

Step 3

Escrow Budget Lock

The total campaign budget is immediately deducted from the brand's wallet balance and committed to escrow, guaranteeing that approved creator work is pre-funded.

Step 4

Submission Review & Curation

Brand evaluates submitted live videos in the review queue: Approve (enters view tracking), Request Revision (up to 2 revision rounds with specific notes), or Reject.

Step 5

Settlement & Final Report

When the budget is exhausted or the deadline passes, views are tallied, earnings credited to creators, and unused escrow balances returned to the brand.

Clipper Workflow

05 / END-TO-END CREATOR JOURNEY

How a creator discovers campaigns, connects accounts, and earns payouts:

Step 1

Campaign Discovery & Materials

Creator explores available campaigns on the marketplace, reviews narrative guidelines, and downloads raw footage or asset folders.

Step 2

TikTok Bio Verification Handshake

Creator submits their TikTok username. The system generates a temporary verification token (KD-XXXX, 10-minute expiry). The creator pastes it into their TikTok bio, and an automated scraper verifies ownership. Once confirmed, the account is permanently tied (@@unique([platform, username])).

Step 3

Produce & Post to TikTok (Post-First Model)

Following modern market standards (Konten.com, Clippo.id), creators edit clips and publish them directly to TikTok first using the mandatory tags and audio guidelines.

Step 4

In-Context Video Submission

On the campaign page, the creator opens the submission modal dialog, selects the recently published TikTok video from a live feed picker (or inputs the live link directly), and submits.

Step 5

View Tracking & Payout

Once approved by the brand, the clip earns money based on verified view counts multiplied by the campaign CPM. Earnings can be withdrawn directly to Indonesian bank accounts or e-wallets.

Feature Inventory

06 / IMPLEMENTED SUBSYSTEMS

Subsystems currently functional across both backend and frontend:

Authentication & Session Complete

Credential auth (email + Bcrypt hashed password), role-guarded JWT payloads, secure HTTP-only cookies, and role-based route redirects.

Brand Wallet & Escrow Complete

Real-time balance tracking, pending deposit verification requests, withdrawal requests, transaction ledgers, and atomic campaign escrow deductions.

6-Step Campaign Creation Wizard Complete

Multi-step wizard with local autosave, draft recovery, character count trackers, reward math validation (CPM, min/max views, budget), and escrow confirmation.

TikTok Account Linking & Handshake Complete

Bio verification token (KD-XXXX) generator, automated live bio scraping, anti-hijacking constraints, and permanent avatar storage on Supabase Storage.

Post-First Video Submission Dialog Complete

Split modal dialog on campaign detail page: Brief acceptance → Verified handle selection → TikTok video picker → Live preview and submission stamp.

Brand Curation & Review Queue Complete

Interactive queue for brand advertisers to inspect live submitted videos, approve clips, request revisions with notes (max 2 rounds), or reject invalid submissions.

Technology Stack

07 / ARCHITECTURE FOUNDATION

Built with an enterprise-grade TypeScript stack across backend services and frontend clients:

Backend Core (backend/)
  • Runtime: Node.js & TypeScript
  • API Framework: Express 5.1
  • ORM: Prisma ORM 7.9
  • Database: PostgreSQL (hosted on Supabase)
  • Data Validation: Zod 4.4
  • Security: Helmet, CORS, Cookie-parser, Bcrypt, JWT
  • Asset Storage: Supabase Storage (thumbnails, avatars)
Frontend Client (frontend/)
  • Framework: React 19 & TypeScript
  • Build Tool: Vite 8
  • Styling: Tailwind CSS v4 & Lucide Icons
  • Query & Caching: TanStack Query v5
  • HTTP Client: Axios with centralized error mapping
  • Forms: React Hook Form + Zod Resolvers
  • Primitives: Radix UI & shadcn/ui components
  • Routing: React Router v8 (Data Router + Code Splitting)

Quickstart Guide

09 / LOCAL ENVIRONMENT SETUP

Run both services locally in under 3 minutes:

1. Start the Backend API

Terminal — backend 
cd backend
npm install
cp .env.example .env
npx prisma generate
npx prisma db push
npm run dev

The Express server will start on http://localhost:3000.

2. Start the Frontend Client

Terminal — frontend 
cd frontend
npm install
npm run dev

Open http://localhost:5173 in your browser. All API requests are proxied automatically to port 3000.
